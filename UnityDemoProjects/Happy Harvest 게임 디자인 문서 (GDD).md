# Happy Harvest 게임 디자인 문서 (GDD)

Nov 17, 2026 · @YongHwan Lee

Unity 공식 2D URP 샘플 Happy Harvest(Asset Store 1.6x, Unity 6000.3.10f1)를 첨부된 GDD 템플릿 순서대로 기술한 문서다. 샘플에 실제로 구현된 것만 적었고(소스·씬·데이터 분석 기준), 강의에서 학생이 확장할 자리는 「확장 여지」로 따로 표시했다. 학생은 이 문서를 복사해 자기 팀의 확장 GDD를 쓴다.

## 1. 기본 정보

| 항목 | 내용 |
| --- | --- |
| 게임명 | Happy Harvest |
| 장르 | 2D 탑다운 농장 시뮬레이션 (농사·경영, 단일 하루가 반복되는 리듬) |
| 게임 요소 (플레이어가 재미로 하는 기본 활동) | ① 땅 갈기 ② 물 주기 ③ 씨앗 심기 ④ 자라는 것 기다리기 ⑤ 수확하기 ⑥ 수확물 팔고 씨앗 사기 ⑦ 농장 돌아다니기(동물·사과나무·낮밤 구경) |
| 플레이어 수 | 1인 |

이 게임의 재미는 경쟁이나 달성이 아니라 "심고 → 기다리고 → 거두는" 짧은 순환을 반복하며 밭이 차는 것을 보는 데 있다. 목표·실패·시간 압박이 없는 "코지(cozy)" 게임이다.

## 2. 기술 사양

## 3. 게임플레이

게임은 작은 시골집 안에서 시작한다. 플레이어는 밀짚 모자를 쓴 소년 농부로, 주머니엔 동전 10닢과 호미·물뿌리개·바구니, 그리고 밀·옥수수·당근 씨앗이 열 봉지씩 들어 있다. 문을 나서면 아침 9시의 농장이 펼쳐진다 — 이미 자라고 있는 밀밭과 옥수수밭, 연못, 사과나무, 닭과 돼지가 돌아다니는 울타리, 그리고 장터의 가판대.

플레이어는 E/Q 키나 마우스 휠로 손에 든 도구를 바꾼다. 호미를 들고 맨땅을 클릭하면 흡이 튜고 갈아진 고랑이 생긴다. 물뿌리개로 적시면 흙이 진한 갈색으로 변하고 1분 동안 젖어 있다. 씨앗 봉지를 들고 클릭하면 새싹이 돋고, 흙이 젖어 있는 동안만 자란다 — 물을 안 주면 성장이 멈추고, 아주 오래 내버려 두면 말라 죽는다. 15초이면 다 자란다. 바구니를 들고 다 자란 작물을 클릭하면 수확물이 튜어오르며 주머니에 들어간다. 옥수수는 한 번 심으면 두 번 거둘 수 있고, 밀과 당근은 한 번뿐이다.

가판대를 클릭하면 상점이 열린다. 수확한 옥수수는 개당 10닢, 당근도 10닢, 밀은 2닢에 팔린다. 살 수 있는 것은 밀 씨앗(1닢)과 옥수수 씨앗(15닢)뿐 — 당근 씨앗은 팔지 않으므로 처음 받은 열 봉지가 전부다. 옥수수 한 봉지에 15닢을 투자하면 수확 두 번에 40닢이 돌아온다. 그렇게 번 돈으로 밭을 늘리는 것이 이 게임의 유일한 "전략"이다.

그동안 하늘은 2분에 한 바퀴 돈다. 해가 기울면 그림자가 길어지고 가로등이 켜지고 환경음이 밤 벌레 소리로 바뀜다. 밤에도 농사는 그대로 할 수 있고, 집에 들어갔다 나와도 밭은 그대로다. 덤불을 지나면 잎이 날리고, 나무 뒤로 들어가면 나무가 투명해진다. 끝은 없다 — 플레이어가 그만두고 싶을 때까지 농장의 하루가 반복된다.

**핵심 기능**

1. 손맛이 보이는 경작 — 클릭 한 번이 타일·소리·먼지 파티클·캐릭터 동작으로 동시에 돌아온다.
2. 라이트로 그리는 하루 — 2분 주기의 태양·그림자·가로등·비가 밭을 계속 바꿔 보여준다.
3. 세 작물의 다른 경제 — 싼 밀(안전), 비싼 옥수수(두 번 수확, 큰 이익), 구할 수 없는 당근(유한 자원).
4. 살아 있는 농장 — 배회하는 동물, 흔들리는 덤불, 투명해지는 나무, 물결과 코스틱.

## 4. 디자인 문서

**디자인 지침 (창작 제약과 전체 목표)**

- 전체 목표: 2D URP의 라이트·그림자·스켈레탈 애니메이션·타일맵·VFX를 한 화면에서 보여주는 것. 게임성은 이를 뒤받침할 만큼만.
- 모든 입체감은 런타임 라이트가 만든다. 스프라이트에 그림자나 하이라이트를 그리지 않는다(노멀 맵·마스크 맵으로).
- 땅의 상태는 타일맵에만 있다. 위치 기반 게임 로직은 셀 좌표(Vector3Int)로만 말한다.
- 작물·아이템·밸런스 수치는 코드가 아니라 ScriptableObject 에셋에. 새 작물은 코드 0줄로 추가되어야 한다.
- 폭력·실패·시간 압박 없음. 말라 죽는 작물조차 3000초(하루 25번)를 방치해야 한다.
- 색·형태: 듥근 실루엣, 따뜻한 팔레트, 림 라이트가 캐릭터와 소품을 배경에서 떠어낸다.
- 재사용 전제: 세이브·씬 전환·낮밤·인벤토리는 다른 프로젝트에 그대로 가져갈 수 있게 독립적으로.

**게임 디자인 정의**

| 항목 | 정의 |
| --- | --- |
| 게임플레이의 중심 | "씨앗 한 봉지를 수확물로 바꾸는 루프"를 반복하며 밭을 늘리는 것 |
| 승리 조건 | 없음 (샘플 의도상). 「확장 여지」 예: N일 안에 코인 M 달성 |
| 패배 조건 | 없음. 「확장 여지」 예: 코인 0 + 씨앗 0 + 자라는 작물 0이면 게임 오버 |
| 레벨 전환 | 레벨이 아니라 장소 전환: 문 트리거 → 페이드 아웃 → 씬 로드 → 스폰 지점 → 페이드 인. 지형 상태는 씬별로 메모리에 보관 |
| 시간 | 하루 = 120초, 시작 09:12. 날짜 개념 없음. 실내에서도 시간은 흐른다(GameManager가 틱) |
| 자원 | 코인 1종. 시작 10. 수입 = 판매뿐, 지출 = 씨앗 구매뿐 |
| 실패의 비용 | 거의 없음. 작물을 죽여도 씨앗 값만 잃는다 |
| 세션 | 자동 저장 없음. F5/F9는 디버그용 — 일반 플레이어는 세션이 끝나면 모두 잃는다 「확장 여지」 |

## 6. 플레이어 정의

**플레이어 정의**: 밀짚 모자를 쓴 소년 농부. 체력·적·전투가 없으므로 "죽을 수 없는" 플레이어다. 할 수 있는 행동은 다섯 가지: 걷기(속도 6), 도구 바꾸기, 인접 1칸에 도구 쓰기, 상호작용 오브젝트 클릭, 문 통과. 무기는 없고 도구 3종이 그 자리를 대신한다.

**플레이어 속성** (각 속성이 바뀔 때의 피드백 포함)

| 속성 | 범위·초기값 | 바뀜 때 | 피드백 |
| --- | --- | --- | --- |
| 위치 | 씬 안 자유 이동, 시작은 집 안 스폰 0 | WASD, 씬 전환 시 스폰 지점으로 | 걷기 애니메이션(DirX/DirY/Speed), 지면별 발소리, 먼지 파티클, 카메라 추적 |
| 바라보는 방향 | 4방향 | 마지막 이동 방향 | 스프라이트 스와프(얼굴·몸), 옆은 X 반전 |
| 타깃 셀 | 플레이어 셀에서 마우스 방향 최대 1칸 | 마우스 이동 | 타깃 마커 표시(쓸 수 있을 때만), 커서 모양 변경 |
| 장착 아이템 | 인벤토리 9칸 중 1칸 | E/Q, 휠 | 손 위 비주얼 교체, HUD 슬롯 하이라이트 |
| 인벤토리 | 9칸 스택형(도구 스택 1, 씨앗·수확물 10). 시작: 도구 3 + 씨앗 3종×10 | 수확·심기·구매·판매 | HUD 아이콘·수량 갱신. 가득 차면 수확이 취소된다(별도 안내 없음 — 「확장 여지」) |
| 코인 | 0 이상, 시작 10 | 판매 +, 구매 − | HUD 숫자 갱신, 판매 효과음(씬에는 미연결) |
| 행동 중 상태 | 도구 사용 중에는 이동 불가 | 애니메이션 종료 시 해제 | 도구별 애니메이션(ToolSwing/Watering/Planting/Picking/Eating) + 효과음 + VFX |

**플레이어 보상** (긍정적 영향을 주는 것)

| 보상 | 효과 | 얻는 방법 |
| --- | --- | --- |
| 수확물 (밀·옥수수·당근) | 판매해 코인 2 / 10 / 10 | 다 자란 작물을 바구니로 수확. 옥수수는 한 번 심으면 2회, 회당 2개 |
| 코인 | 씨앗 구매 | 판매 |

## 7. 사용자 인터페이스

**조작** (Player.inputactions / Gameplay 맵)

| 행동 | 입력 | 비고 |
| --- | --- | --- |
| 이동 | WASD / 방향키 | 8방향 이동, 바라보는 방향은 4방향 |
| 사용 | 마우스 왼쪽 / Space | 마우스 아래 상호작용 오브젝트 우선, 없으면 타깃 셀에 도구 |
| 도구 전환 | E / Q, 휠 위·아래 | 9칸 순환 |
| 저장 / 불러오기 | F5 / F9 | 코드에 직접 박힘, UI 없음 |
| 상점·창고 닫기 | UI 버튼 | — |
| 터치 / 게임패드 | 없음 | 마우스 위치를 직접 읽으므로 바인딩 추가만으로는 안 됨 |

**HUD** (UI Toolkit, UIHandler): 하단 인벤토리 바 9칸(아이콘·수량·장착 표시), 코인 숫자, 날씨 아이콘, 상황별 커서(기본/상호작용), 씬 전환 페이드. 상점 패널: 왼쪽 구매 목록(아이콘·가격), 오른쪽 보유 수확물 판매. 시간·날짜 표시 없음.

**화면에 없는 정보(플레이어가 알 수 없는 것)**: 작물의 남은 성장 시간, 흙이 마르기까지 남은 시간, 현재 시각, 인벤토리가 가득 찼다는 사실, 저장 방법. 농장 장르 관습에 비추어 모두 「확장 여지」다.

**최악의 레이아웃 검토** (템플릿이 요구하는 질문): 마우스를 쓸 수 없으면 상호작용 대상을 고를 수 없어 플레이 불가 — 키보드만으로는 "바라보는 방향 앞 칸" 규칙이 필요하다. 키보드 없이 마우스만으로는 이동이 불가 — 클릭 이동이 필요하다. 터치 기기는 둘 다 해당하므로 모바일 지원은 "가상 스틱 + 탭 타깃" 두 가지를 동시에 해결해야 한다.
