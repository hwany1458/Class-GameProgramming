## 0. 이 문서를 읽는 법

| 칸 | 묻는 것 | 들어가는 내용 |
|---|---|---|
| 요구사항 | 무엇을 만들까 | 게임이 지켜야 할 규칙 한 줄 |

**★ 표시**는 교재 원본에 없거나 잘못되어 이번에 고쳐 넣은 자리다. 그 줄이 없으면 컴파일은 되어도 게임이 동작하지 않는다.

### 다루는 스크립트 7개

| 파일 | 붙는 곳 | 책임 |
|---|---|---|
| `EnemyMgr.cs` | CurEnemyMgr (빈 오브젝트) | 적과 웨이브 총괄. 적을 만들고, 가장 가까운 적을 찾아 주고, 전멸을 판정 |
| `EnemyMove.cs` | 적 프리팹 | 적 한 마리의 이동. NavMeshAgent 로 길을 따라 걷고 도착을 판정 |
| `Enemy.cs` | 적 프리팹 | 적 한 마리의 체력. 피해를 받고 0 이 되면 사라짐 |
| `TowerMgr.cs` | CurTowerMgr (빈 오브젝트) | 건설 담당. 클릭한 칸을 알아내고 골드를 확인하고 타워를 세움 |
| `Tower.cs` | 타워 프리팹 | 타워 한 기의 사격. 적을 찾고 겨누고 발사체를 만듦 |
| `Projectile.cs` | 발사체 프리팹 | 발사체 한 발. 목표로 날아가고 닿으면 피해를 줌 |
| `GameMgr.cs` | CurGameMgr (빈 오브젝트) | 골드와 HP 총괄. 돈을 쓰고 벌고, 체력을 깎고, 게임 오버를 알림 |

### 서로를 아는 방법

```
EnemyMove ──도착──┐                    ┌──적 요청── Tower
                  ├──→ EnemyMgr ←──────┤              │
Enemy ────사망────┘        │           └─OnDamage──Projectile
                           │ addGold / damageHP        ↑
                           ↓                        Instantiate
                        GameMgr ←──consumeGold── TowerMgr
```

- 적 쪽과 타워 쪽은 **서로를 직접 모른다**. 둘 다 `EnemyMgr` 를 거쳐 만난다.
- 돈과 목숨은 `GameMgr` **한 곳에만** 있다.
- 연결은 Inspector 에서 끼운다(EnemyMgr → Game Mgr, TowerMgr → Enemy Mgr · Game Mgr · Build Tile Map · Build Tower). 적과 발사체는 생성될 때 `SetEnemeyMgr()` 로 코드가 직접 넘겨 준다.

## 3. 요구사항별 상세

### 요구사항 1 — 적은 정해진 길을 따라 스스로 이동한다

**화면에서 보이는 것**
- 적이 StartPoint 에서 나타난다
- 길이 꺾여도 알아서 따라 돈다
- 벽이나 건설 구역을 밟지 않는다
- EndPoint 에 닿으면 사라진다

**그러려면 필요한 기능**
1. 걸어갈 수 있는 영역을 미리 구워 두기 (Bake)
2. 목적지를 한 번 알려 주기
3. 매 프레임 "도착했는가" 재기
4. 도착하면 매니저에 알리고 사라지기

**담당 함수 — `EnemyMove.cs`**

| 함수 | 시점 | 하는 일 |
|---|---|---|
| `SetTarget(Transform)` | 생성 직후 `EnemyMgr` 가 호출 | `endObject` 에 목적지를 넣는다 |
| `SetEnemeyMgr(EnemyMgr)` | 생성 직후 `EnemyMgr` 가 호출 | 도착을 알릴 상대를 기억한다 |
| `Start()` | 생성 다음 프레임 1회 | Agent 를 찾고, 2D 설정을 하고, 목적지를 건다 |
| `Update()` | 매 프레임 | 도착 여부만 판정한다. 이동은 Agent 가 한다 |

```csharp
public void SetTarget(Transform target)
{
    if (target == null) { Debug.LogError("target is null!"); return; }
    endObject = target;                      // ★ 교재에 이 줄이 빠져 있었다
}

void Start()
{
    enemyAgent = GetComponent<NavMeshAgent>();
    enemyAgent.updateRotation = false;       // 2D 에서 반드시 필요한 두 줄
    enemyAgent.updateUpAxis   = false;
    enemyAgent.SetDestination(endObject.position);   // 목적지는 한 번만 준다
}

void Update()
{
    if (!enemyAgent.pathPending &&
        enemyAgent.remainingDistance <= arrivalDistance &&
        (!enemyAgent.hasPath || enemyAgent.velocity.sqrMagnitude < sqrVelocityThreshold))
    {
        if (enemyMgr != null) enemyMgr.DieEnemyAtDestination(gameObject);
        Destroy(gameObject);
    }
}
```

**핵심 변수**

| 변수 | 하는 일 | 빠뜨리거나 잘못 쓰면 |
|---|---|---|
| `enemyAgent` | NavMeshAgent 부품. 길 찾기를 전부 담당 | 움직이지 않는다 (NullReference) |
| `endObject` | 가야 할 목적지 Transform | ★ `SetTarget()` 에서 대입하지 않으면 제자리 |
| `arrivalDistance = 0.1f` | 남은 거리가 이보다 작으면 도착으로 본다 | 크면 일찍 사라지고, 너무 작으면 영원히 도착하지 못한다 |
| `sqrVelocityThreshold = 0.01f` | 거의 멈췄는지 판정. **제곱끼리** 비교 | ★ `0.1f` 와 그대로 비교하면 판정이 10배 어긋난다 |

**에디터에서 먼저 해야 하는 일** (교재에 빠져 있는 단계)
1. Package Manager 에서 NavMeshPlus(2D) 설치
2. 빈 오브젝트에 Navigation Surface 추가 → Rotate Surface to XY → Bake
3. 도로 타일맵에 Navigation Modifier(Walkable), 건설·배경 타일맵에 Not Walkable 지정 후 다시 Bake

**참고 문서**
- AI Navigation 패키지 — https://docs.unity3d.com/Packages/com.unity.ai.navigation@2.0/manual/index.html
- NavMeshAgent — https://docs.unity3d.com/ScriptReference/AI.NavMeshAgent.html
- NavMeshPlus(2D) — https://github.com/h8man/NavMeshPlus

### 요구사항 2 — 적은 웨이브 단위로 나온다

**화면에서 보이는 것**
- 적이 한 번에 쏟아지지 않는다
- 같은 간격으로 한 마리씩 나온다
- 다 잡으면 잠시 아무도 나오지 않는다
- 다음 묶음은 더 많거나 더 빠르다

**그러려면 필요한 기능**
1. 웨이브 설정을 목록으로 갖고 있기
2. 일정 간격마다 한 마리씩 만들기
3. 살아 있는 적을 목록으로 세기
4. 목록이 비면 쉬었다가 다음 웨이브

**담당 함수 — `EnemyMgr.cs`**

| 함수 | 시점 | 하는 일 |
|---|---|---|
| `Awake()` | 1회 | 스크립트가 살아 있음을 로그로 알린다 |
| `Start()` | 1회 | `gameMgr` 를 확보하고 `StartGame()` 호출 |
| `StartGame()` | 게임 시작 / ContextMenu | 상태를 초기화하고 첫 웨이브를 연다 |
| `SpawnEnemyRoutine()` | 웨이브 시작마다 | 범위 검사 → 첫 마리 즉시 생성 → `InvokeRepeating` |
| `SpawnEnemy()` | 생성 간격마다 | 적 1마리 생성 + 연결 + 목록 추가 |
| `CheckWaveClear()` | 적이 사라질 때마다 | 전멸이면 `curWaveIdx++` 후 지연 호출 |
| `StopGame()` | 게임 오버 시 | 더 이상 적을 만들지 않는다 |

```csharp
[System.Serializable]
public class EnemyWaveData
{
    public int   enemyCount;           // 이 웨이브에 내보낼 적 수
    public float spawnInterval;        // 적과 적 사이의 간격(초)
    public float delayBeforeNextWave;  // 전멸 후 다음 웨이브까지 대기(초)
}

private void SpawnEnemyRoutine()
{
    if (!isStartGame) return;
    if (curWaveIdx >= waves.Count) { CompleteGame(); return; }  // ★ 범위 검사를 먼저

    isSpawningWave = true;  isWaitNextWave = false;
    spawnedEnemyNumInWave = 0;  enemyListinCurWave.Clear();

    SpawnEnemy();                                   // 첫 마리는 즉시
    // ★ SpawnEnemy() 안에서 이미 1 증가했으므로 + 1 을 더하면 안 된다
    if (spawnedEnemyNumInWave < currentWave.enemyCount)
        InvokeRepeating("SpawnEnemy", interval, interval);
}
```

**웨이브를 움직이는 상태 변수 네 개**

| 상태 | 플래그 | 뜻 |
|---|---|---|
| 대기 | `isStartGame = false` | 게임이 아직 시작되지 않았다 |
| 생성 중 | `isSpawningWave = true` | 이 웨이브의 적을 차례로 내보내는 중 |
| 전투 중 | 둘 다 `false` | 생성은 끝났고 적이 살아서 걷고 있다 |
| 다음 대기 | `isWaitNextWave = true` | 전멸했다 — `delayBeforeNextWave` 만큼 쉬는 중 |

**두 개의 카운터**

| 변수 | 뜻 |
|---|---|
| `spawnedEnemyNumInWave` | 이번 웨이브에서 지금까지 몇 마리를 내보냈나. `enemyCount` 에 도달하면 생성 중단 |
| `enemyListinCurWave` | 지금 살아서 걷고 있는 적의 목록. **비면 "전멸"**. 타워가 적을 찾을 때 뒤지는 목록도 이것 |

> ★ **교재의 계산 실수** — `SpawnEnemy()` 가 이미 카운터를 1 올리는데 교재는 거기에 `+ 1` 을 또 더한다. 그래서 2마리짜리 웨이브가 1마리만 나온다.

**난이도는 코드가 아니라 숫자로** — Inspector 의 Waves 리스트에 칸을 늘리고 세 숫자(`enemyCount` / `spawnInterval` / `delayBeforeNextWave`)만 바꾸면 난이도 곡선이 달라진다. 코드는 그대로다.

**참고 문서**
- Instantiating Prefabs — https://docs.unity3d.com/Manual/InstantiatingPrefabs.html
- InvokeRepeating — https://docs.unity3d.com/ScriptReference/MonoBehaviour.InvokeRepeating.html

### 요구사항 3 — 클릭한 칸에 타워를 세운다

**화면에서 보이는 것**
- 길 옆 초록 칸을 누르면 타워가 선다
- 타워가 칸의 정확히 가운데에 놓인다
- 이미 타워가 있는 칸은 반응이 없다
- 길이나 배경을 눌러도 아무 일 없다

**그러려면 필요한 기능** — 마우스 한 번이 **좌표계를 세 번 갈아탄다**

| 단계 | 좌표계 | 바꿔 주는 것 | 예 |
|---|---|---|---|
| 1 | 화면 좌표 Screen | `Mouse.current.position` | `(640, 360) px` |
| 2 | 월드 좌표 World | `Camera.ScreenToWorldPoint` | `(2.37, −0.84, 0)` |
| 3 | 셀 좌표 Cell | `Tilemap.WorldToCell` | `(2, −1, 0)` |

**담당 함수 — `TowerMgr.cs`**

```csharp
private void Update()                                  // ★ 교재에 없던 함수
{
    if (Mouse.current == null) return;
    if (Mouse.current.leftButton.wasPressedThisFrame) BuildTower();
}

void BuildTower()
{
    Vector2 mousePos      = Mouse.current.position.ReadValue();
    Vector3 mouseWorldPos = mainCamera.ScreenToWorldPoint(
            new Vector3(mousePos.x, mousePos.y, mainCamera.nearClipPlane));
    mouseWorldPos.z = 0f;                              // ★ 2D 이므로 반드시

    Vector3Int cellPosition = buildTileMap.WorldToCell(mouseWorldPos);

    if (CanBuildTower.ContainsKey(cellPosition))  return;   // 이미 타워가 있는 칸
    if (buildTileMap.GetTile(cellPosition) == null) return; // 타일이 없는 칸
    if (!gameMgr.checkGold(towerPrice))           return;   // ★ gameMgr. 이 빠져 CS0103

    Vector3 worldPosition  = buildTileMap.CellToWorld(cellPosition);
    Vector3 centerPosition = worldPosition + buildTileMap.cellSize * 0.5f;  // 칸 한가운데

    GameObject createdTower = Instantiate(buildTower, centerPosition, Quaternion.identity);
    createdTower.name = "BasicTower_Pos(" + cellPosition.x + "," + cellPosition.y
                      + ")_ID" + towerCounter;
    towerCounter++;                                    // ★ 번호를 올려 이름 충돌을 막는다
    CanBuildTower[cellPosition] = createdTower;

    createdTower.GetComponent<Tower>().SetEnemeyMgr(enemyMgr);
    createdTower.transform.SetParent(transform);
    gameMgr.consumeGold(towerPrice);                   // ★ 골드를 실제로 깎는다
}
```

**핵심 변수**

| 변수 | 하는 일 | 빠뜨리면 |
|---|---|---|
| `buildTileMap` | 건설 가능 칸을 아는 타일맵 | 건설 구역을 판정할 수 없다 |
| `buildTower` | 세울 타워 프리팹 | 세울 것이 없다 |
| `CanBuildTower` | 칸 → 타워 기록장 `Dictionary<Vector3Int, GameObject>` | 같은 칸에 타워가 겹쳐 쌓인다 |
| `mainCamera` | 좌표 변환용 카메라 | ★ `Start()` 에서 `Camera.main` 을 받지 않으면 NullReference |
| `towerCounter` | 세운 타워 수 (이름 붙이기용) | 이름이 전부 같아진다 |

> **건설 가능 구역을 코드가 아니라 그림이 정한다** — `GetTile()` 이 `null` 이 아닌 칸, 즉 Building 타일맵에 타일이 칠해진 칸만 건설할 수 있다. 맵을 바꾸려면 타일을 칠하면 된다.

> ★ `mouseWorldPos.z = 0f;` 를 빠뜨리면 Grid 의 Cell Size Z 설정에 따라 셀 z 가 어긋나 `GetTile()` 이 엉뚱하게 `null` 을 돌려준다. 클릭이 전부 무시되는 증상으로 나타난다.

**에디터에서 먼저 해야 하는 일**
- Package Manager → Input System 설치
- Project Settings → Player → Active Input Handling 을 "Input System Package (New)" 또는 "Both" 로

### 요구사항 4 — 타워는 찾고 · 겨누고 · 쏜다

**화면에서 보이는 것**
- 적이 가까이 와야 쏘기 시작한다
- 쉬지 않고가 아니라 일정 간격으로 쏜다
- 여러 마리가 있으면 가장 가까운 쪽
- 적이 멀어지면 발사가 멈춘다

**매 물리 프레임 세 단계**

| 단계 | 코드 | 설명 |
|---|---|---|
| ① 찾는다 | `GetClosestEnemy(position, range)` | 사정거리 안 가장 가까운 적 하나. 없으면 `null` |
| ② 겨눈다 | `targetDir = (enemyPos − myPos).normalized` | 길이 1짜리 방향 벡터. ★ 이 한 줄이 교재에 없다 |
| ③ 쏜다 | `Instantiate(projectTile)` + 값 3개 전달 | `waitAttackTime` 마다 한 발 |

```csharp
void FixedUpdate()
{
    curAttackTime += Time.fixedDeltaTime;
    if (curAttackTime > waitAttackTime)
    {
        findEnemy = enemyMgr.GetClosestEnemy(transform.position, attackRange);
        if (findEnemy != null)
        {
            // ★ 교재에 없던 핵심 한 줄. 없으면 발사체가 제자리에 머문다
            targetDir = (findEnemy.transform.position - transform.position).normalized;

            GameObject projectileObject =
                Instantiate(projectTile, transform.position, Quaternion.identity);
            Projectile p = projectileObject.GetComponent<Projectile>();
            p.SetDirection(targetDir);
            p.SetTarget(findEnemy.transform);
            p.SetEnemeyMgr(enemyMgr);
        }
        curAttackTime = 0.0f;
    }
}
```

```csharp
// EnemyMgr — ★ 교재에 정의 자체가 없다. 없으면 Tower·Projectile 이 컴파일되지 않는다
public GameObject GetClosestEnemy(Vector3 position, float range)
{
    GameObject closest = null;
    float closestSqr = range * range;            // 제곱끼리 비교해 제곱근 연산을 피한다
    foreach (var e in enemyListinCurWave)
    {
        if (e == null) continue;                 // 이미 파괴된 적은 건너뛴다
        float sqr = (e.transform.position - position).sqrMagnitude;
        if (sqr <= closestSqr) { closestSqr = sqr; closest = e; }
    }
    return closest;
}
```

**핵심 변수**

| 변수 | 기본값 | 하는 일 |
|---|---|---|
| `attackRange` | `3.0f` | 사정거리. Scene 뷰에서 노란 원으로 보인다 (`OnDrawGizmosSelected`) |
| `waitAttackTime` | `1.0f` | 발사 간격(초) |
| `curAttackTime` | `0.0f` | 쌓인 시간. `waitAttackTime` 을 넘으면 쏘고 0 으로 되돌린다 |
| `findEnemy` | — | 지금 겨눈 적 |
| `targetDir` | `Vector3.zero` | 적 쪽 단위 방향 벡터 |
| `projectTile` | — | 발사체 프리팹 (교재 표기 그대로) |

> **왜 `FixedUpdate` 인가** — `Update` 는 컴퓨터 성능에 따라 호출 횟수가 달라진다. 물리 주기(기본 0.02초)로 쏴야 발사 간격이 모든 컴퓨터에서 같다.

> **왜 `sqrMagnitude` 인가** — 제곱근은 비싸다. 거리끼리 비교만 하면 되므로 양쪽을 제곱한 채로 비교한다. 단, 기준값도 반드시 제곱해야 한다 (`range * range`).

### 요구사항 5 — 명중하면 체력이 깎인다

**화면에서 보이는 것**
- 발사체가 적을 따라가며 날아간다
- 닿는 순간 발사체가 사라진다
- 적은 몇 발을 맞아야 사라진다
- 빗나간 발사체도 결국 사라진다

**담당 함수**

```csharp
// Projectile
private void Start() { Destroy(gameObject, lifeTime); }   // ★ 빗나간 발사체 정리

private void Update()                                     // ★ 교재가 통째로 생략한 부분
{
    if (targetObj != null) targetPosition = targetObj.position;      // 유도탄
    else if (enemyMgr != null)                                       // ★ 목표가 죽었으면
    {                                                                //    다른 적으로 갈아탄다
        GameObject next = enemyMgr.GetClosestEnemy(transform.position, 3.0f);
        if (next != null) { targetObj = next.transform; targetPosition = targetObj.position; }
    }
    Vector3 toTarget = targetPosition - transform.position;
    if (toTarget.sqrMagnitude > errorDistance * errorDistance)
        moveDirection = toTarget.normalized;
    else if (targetObj == null) { Destroy(gameObject); return; }

    transform.Translate(moveDirection * moveSpeed * Time.deltaTime, Space.World);
}

private void OnTriggerEnter2D(Collider2D collision)
{
    if (isHit) return;                           // ★ 같은 프레임 중복 명중 방지
    if (collision.CompareTag("Enemy"))           // ★ 적 프리팹에 Enemy 태그가 있어야 한다
    {
        Enemy enemy = collision.gameObject.GetComponent<Enemy>();
        if (enemy != null) { isHit = true; enemy.OnDamage(attackVal); Destroy(gameObject); }
    }
}

// Enemy
public void OnDamage(float damageValue)
{
    if (isDead) return;                          // ★ 같은 프레임에 두 번 죽지 않게
    hpValue -= damageValue;
    if (hpValue <= 0)
    {
        hpValue = 0; isDead = true;
        if (enemyMgr != null) enemyMgr.DieEnemy(gameObject);
        Destroy(gameObject);
    }
}
```

**핵심 변수**

| 변수 | 기본값 | 하는 일 |
|---|---|---|
| `moveSpeed` | `5.0f` | 발사체 속도. 적보다 느리면 영원히 못 따라잡는다 |
| `attackVal` | `100.0f` | 한 발의 공격력. `hpValue` 와의 비가 "몇 발에 죽는가" |
| `lifeTime` | `5f` | 생존 시간. 지나면 자동 소멸 |
| `errorDistance` | `0.1f` | 목표에 거의 닿았을 때 방향을 다시 계산하지 않는 기준 (떨림 방지) |
| `isHit` | `false` | ★ 한 발이 두 번 터지지 않도록 잠근다 |
| `hpValue` | `100.0f` | 적의 남은 체력 |
| `isDead` | `false` | ★ 이미 죽은 적을 또 죽이지 않는다 |

**필요한 오브젝트 설정** (교재 57쪽 + 빠진 단계)
- 발사체: Circle Collider 2D (Is Trigger 체크), Rigidbody 2D (Gravity Scale 0)
- ★ **적 프리팹에 `"Enemy"` 태그** — 교재에 빠진 단계. 없으면 `CompareTag` 가 영원히 `false`

**참고 문서**
- Colliders — https://docs.unity3d.com/Manual/CollidersOverview.html
- Rigidbody 2D — https://docs.unity3d.com/Manual/class-Rigidbody2D.html
- Tags — https://docs.unity3d.com/Manual/Tags.html

### 요구사항 6 — 골드를 쓰고 번다

**화면에서 보이는 것**
- 시작할 때 골드 300 을 갖고 있다
- 타워를 세우면 100 이 줄어든다
- 적을 잡으면 20 이 늘어난다
- 골드가 모자라면 타워가 서지 않는다

```csharp
public float curGold = 300;

public bool checkGold(float price)
{
    return curGold >= price;                 // ★ ? true : false 제거 — 비교식이 이미 bool
}

public bool consumeGold(float price)         // ★ void → bool. 성공 여부를 알려 준다
{
    if (!checkGold(price)) return false;     // ★ 잔액 검사 추가 — 음수 방지
    curGold -= price;  return true;
}

public void addGold(float amount)            // ★ 교재에 아예 없던 함수
{
    curGold += amount;                       // EnemyMgr.DieEnemy() 가 부른다
}
```

**숫자 네 개가 난이도를 정한다**

| 숫자 | 어디에 | 기본값 | 올리면 |
|---|---|---|---|
| `curGold` | GameMgr | 300 | 처음부터 여러 기를 세울 수 있어 쉬워진다 |
| `towerPrice` | TowerMgr | 100 | 한 기를 어디에 세울지 고민하게 된다 |
| `killReward` | EnemyMgr | 20 | 잡을수록 눈덩이처럼 유리해진다 |
| `enemyDamage` | EnemyMgr | 10 | 한 마리만 놓쳐도 치명적이 된다 |

> **좋은 디펜스 게임의 조건** — 세울 수 있는 타워 수보다 막아야 할 길목이 많아야 한다. 그래야 "어디에 세울까" 가 고민이 되고, 그 고민이 곧 게임의 재미다. 골드가 넉넉해 모든 칸을 채울 수 있으면 선택이 사라진다.

> ★ **교재가 빠뜨린 연결** — `consumeGold()` 와 `damageHP()` 를 부르는 곳이 교재 코드에 없다. 그래서 타워가 공짜이고 HP 가 줄지 않아 **이기지도 지지도 않는 게임**이 된다.

### 요구사항 7 — 뚫리면 HP 가 줄고, 0 이면 끝

```csharp
// EnemyMgr — 적이 사라지는 두 가지 경우를 구분한다
public void DieEnemy(GameObject e)                  // 처치됨 — 상을 준다
{
    if (gameMgr != null) gameMgr.addGold(killReward);
    RemoveEnemy(e);
}

public void DieEnemyAtDestination(GameObject e)     // 도착함 — 벌을 받는다
{
    if (gameMgr != null) gameMgr.damageHP(enemyDamage);   // ★ 교재에 없던 연결
    RemoveEnemy(e);
}

private void RemoveEnemy(GameObject e)
{
    enemyListinCurWave.Remove(e);
    CheckWaveClear();                                // 어느 쪽이든 전멸 판정은 한 곳에서
}

// GameMgr
public void damageHP(float damage)
{
    if (isGameOver) return;                          // ★ 이미 끝났으면 더 깎지 않는다
    curHP -= damage;
    if (curHP <= 0) { curHP = 0; GameOver(); }       // ★ 음수로 내려가지 않게 고정
}

private void GameOver()
{
    isGameOver = true;                               // ★ 플래그를 세운다
    EnemyMgr enemyMgr = FindFirstObjectByType<EnemyMgr>();   // ★ 추가
    if (enemyMgr != null) enemyMgr.StopGame();
}
```

**두 개의 사슬**

| | 막아 냈다 (명중 → 골드) | 뚫렸다 (도착 → HP 감소) |
|---|---|---|
| 1 | `Projectile.OnTriggerEnter2D()` | `EnemyMove.Update()` |
| 2 | `isHit = true` | `dist < arrivalDistance` |
| 3 | `Enemy.OnDamage(attackVal)` | `EnemyMgr.DieEnemyAtDestination()` |
| 4 | `hpValue <= 0 → isDead = true` | `GameMgr.damageHP(enemyDamage)` |
| 5 | `EnemyMgr.DieEnemy(gameObject)` | `curHP <= 0 → GameOver()` |
| 6 | `GameMgr.addGold(killReward)` | `EnemyMgr.StopGame()` |
| 7 | `EnemyMgr.CheckWaveClear()` | `EnemyMgr.CheckWaveClear()` |

두 사슬 모두 `EnemyMgr` 를 거쳐 `GameMgr` 로 가고, 마지막에는 `CheckWaveClear()` 로 모인다. 적이 사라지는 이유가 무엇이든 "전멸했는가" 는 **한 곳에서만** 판정한다.

### 요구사항 8 — 모두 막아 내면 클리어

```csharp
private void CheckWaveClear()                    // 적이 하나 사라질 때마다 불린다
{
    if (!isStartGame)                 return;     // 게임이 끝났다
    if (isWaitNextWave)               return;     // 이미 다음 웨이브 대기 중
    if (isSpawningWave)               return;     // 아직 생성이 안 끝났다
    if (enemyListinCurWave.Count > 0) return;     // 아직 살아 있는 적이 있다

    isWaitNextWave = true;
    float delay = waves[curWaveIdx].delayBeforeNextWave;
    curWaveIdx++;
    Invoke("SpawnEnemyRoutine", delay);
}

private void SpawnEnemyRoutine()
{
    if (curWaveIdx >= waves.Count) { CompleteGame(); return; }   // ← 클리어 판정
    ...
}

private void CompleteGame()
{
    isStartGame = false;
    CancelInvoke();
    Debug.Log("모든 웨이브를 막아 냈다 — 게임 완료!");
}
```

네 개의 `return` 은 각각 다른 상황을 거른다. 하나라도 빼면 웨이브가 겹쳐 시작되거나, 생성 도중에 "전멸" 로 오판한다.

> **여기부터는 직접 만들 자리** — `CompleteGame()` 과 `GameOver()` 는 지금 Console 로그만 남긴다. UI Canvas 에 "CLEAR" · "GAME OVER" 패널을 만들어 `SetActive(true)` 를 부르면 완성된 게임이 된다.

## 4. 언제 무엇이 실행되는가

| 한 번만 (게임 시작 시) | 쉬지 않고 (매 프레임) | 그 순간에만 (사건 발생 시) |
|---|---|---|
| `EnemyMgr.Awake()` | `EnemyMove.Update()` | `Projectile.OnTriggerEnter2D()` |
| `EnemyMgr.Start()` | `TowerMgr.Update()` | `Enemy.OnDamage()` |
| `EnemyMove.Start()` | `Tower.FixedUpdate()` | `EnemyMgr.DieEnemy()` |
| `TowerMgr.Start()` | `Projectile.Update()` | `EnemyMgr.DieEnemyAtDestination()` |
| `Projectile.Start()` | | `GameMgr.GameOver()` |

- `Instantiate()` 로 만든 오브젝트는 **그 순간 `Awake()`**, **다음 프레임 `Start()`** 가 돈다. 그래서 `SetTarget()` 같은 설정은 `Instantiate()` 직후에 불러도 `Start()` 보다 먼저 들어간다.
- `Destroy()` 는 그 프레임 끝에 실제로 사라진다. 그래서 `isHit` · `isDead` 같은 잠금 플래그가 필요하다.

참고: Order of Execution — https://docs.unity3d.com/Manual/ExecutionOrder.html

## 5. ★ 교재에 없어 직접 채워야 하는 자리

| 어디에 | 무엇을 | 없으면 |
|---|---|---|
| `EnemyMove.SetTarget()` | `endObject = target;` | 목적지가 들어가지 않아 적이 제자리에 선다 |
| `Tower.FixedUpdate()` | `targetDir = (적 위치 − 내 위치).normalized;` | 발사체가 방향을 몰라 제자리에 머문다 |
| `TowerMgr.BuildTower()` | `mouseWorldPos.z = 0f;` | 셀 z 가 어긋나 `GetTile()` 이 `null` 을 돌려준다 |
| `TowerMgr.Update()` | `Mouse.current.leftButton.wasPressedThisFrame` | `BuildTower()` 를 아무도 호출하지 않는다 |
| `EnemyMgr` | `GetClosestEnemy(Vector3, float)` 정의 | `Tower` 와 `Projectile` 이 컴파일되지 않는다 |
| `GameMgr` | `addGold(float)` | 골드를 벌 통로가 없어 경제가 한쪽으로만 흐른다 |
| `EnemyMgr.DieEnemyAtDestination()` | `gameMgr.damageHP(enemyDamage);` | HP 가 줄지 않아 지지 않는 게임이 된다 |
| `TowerMgr.BuildTower()` | `gameMgr.consumeGold(towerPrice);` | 골드가 줄지 않아 타워가 공짜가 된다 |
| 적 프리팹 | `"Enemy"` 태그 | `CompareTag` 가 영원히 `false` — 명중이 일어나지 않는다 |
| 프로젝트 설정 | Input System 설치 + Active Input Handling | `Mouse.current` 가 `null` |
| 씬 | NavMeshPlus Surface + Modifier + Bake | 적이 길을 찾지 못한다 |

| # | 요구사항 | 가장 중요한 함수 한 개 | 가장 중요한 변수 한 개 |
