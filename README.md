# 게임프로그래밍

> 원광대학교 게임콘텐츠학과 2학년 대상 Unity 기반 게임프로그래밍 강의 저장소입니다.  
> 본 저장소는 강의자료, 실습 예제, 과제 안내, Unity 프로젝트 템플릿, 제출 가이드 정리를 목적으로 합니다.

---

## 1. 교과목 개요

**게임프로그래밍**은 Unity 게임 엔진과 C# 프로그래밍을 활용하여 게임 개발의 전 과정을 학습하는 실습 중심 교과목입니다.

게임 개발은 단순히 코드를 작성하는 작업이 아니라, **아이디어와 스토리 구상 → 기획 → 디자인 → 설계 → 개발 → 평가 → 배포**의 흐름으로 진행됩니다. 본 강의에서는 이러한 개발 과정을 이해하고, Unity에서 제공하는 게임 개발 환경을 활용하여 실제 작동하는 2D/3D 게임 콘텐츠를 제작합니다.

학생들은 Unity의 GameObject, Component, Physics, UI, Animation, Particle, Prefab, Scene, Build 기능을 학습하고, C# 스크립트를 통해 게임의 조작, 충돌, 점수, 상태 변화, 게임 오버, 레벨 디자인 등을 구현합니다.

## 13. Unity 프로젝트 업로드 시 주의사항

Unity 프로젝트를 GitHub에 업로드할 때는 모든 파일을 그대로 올리기보다, GitHub에 적합한 파일만 관리하는 것이 좋습니다.

권장 포함 폴더:

```text
Assets/
Packages/
ProjectSettings/
README.md
```

일반적으로 제외하는 폴더:

```text
Library/
Temp/
Obj/
Build/
Builds/
Logs/
UserSettings/
```

Unity용 `.gitignore`를 적용하면 불필요한 대용량 임시 파일 업로드를 줄일 수 있습니다.
